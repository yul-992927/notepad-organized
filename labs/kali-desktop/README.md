# Kali VM 바탕화면 코드

사용자가 열어 둔 VMware의 Kali 바탕화면에서 확인한 **코드 파일 3개**를 정리한 폴더입니다. 원본 로직은 유지하고, 공개 저장소에서 맥락을 알 수 있도록 각 파일 맨 앞에 안전 안내 주석만 추가했습니다.

| 파일 | 내용 |
| --- | --- |
| [`vuln_scan.py`](vuln_scan.py) | 지정한 대상에 대해 `nmap -sV -p-`를 실행하고 결과를 요약하는 Python 스크립트 |
| [`vuln_scan.sh`](vuln_scan.sh) | Nmap 서비스 버전·전체 TCP 포트 스캔을 실행하고 열린 포트를 요약하는 셸 스크립트 |
| [`csrf.py`](csrf.py) | 웹 보안 실습용 HTTP 리스너. POST된 HTML에서 사용자명을 추출해 출력하는 예제 |

## 사용 전 확인

- 본인 소유이거나 테스트에 **명시적으로 허가받은** 시스템·계정·네트워크에서만 사용하세요. 사전 허가 없이 타인을 스캔하거나 계정·정보를 다루는 데 사용하지 마세요.
- 두 스캔 스크립트는 전체 TCP 포트를 검사하고 `scan_...`.txt 결과 파일을 만듭니다. 운영 서비스에 부담을 줄 수 있으니 테스트 범위와 시간을 먼저 정하세요. 실행 환경에 Nmap이 필요합니다.
- `csrf.py`의 `hacked123`은 원본에 있던 실습용 고정 문자열입니다. 이 리스너는 수신 내용을 출력할 뿐이며, 출력 문구만으로 실제 계정 비밀번호 변경 성공이 검증되는 것은 아닙니다. 실제 자격 증명을 입력하거나 수집하지 마세요.
- 코드를 실행·변형·재배포하는 사람은 법률과 정책을 확인하고 필요한 허가를 받아야 합니다. 무단 사용이나 오용으로 인한 책임은 해당 행위자에게 있습니다. 이 안내는 위법 행위를 허용하거나 법적 책임을 자동 면제하지 않습니다. [안전 및 이용 안내](../../docs/LEGAL_AND_SAFETY.md)를 함께 읽어 주세요.

## 공개 범위

VM의 `hash.txt` 및 `scan_...`.txt 결과 파일은 자격 증명·대상 정보 등이 포함될 수 있어 **업로드하지 않았습니다**. 이 폴더에는 위의 코드와 설명만 저장했습니다.
