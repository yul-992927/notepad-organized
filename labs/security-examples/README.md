# 허가된 보안 실습 예제

이 폴더의 코드는 교육·방어 목적의 **본인 소유 또는 사전 허가된 환경**에서만 사용하세요. 무단 로그인 시도, 개인정보 수집, 공격 자동화에 사용하지 마세요. 사용·변형으로 인한 법적 책임은 행위자에게 있으며, [안전 및 이용 안내](../../docs/LEGAL_AND_SAFETY.md)를 함께 확인하세요.

- `rdp_credential_audit.py`: 원본 RDP 계정 조합 확인 실습 코드. 하드코딩된 내부 대상 주소를 제거하고 실행 인자로 받도록 변경했습니다. `rdp_user.db`와 `rdp_pw.db`는 저장소에 포함하지 않습니다. 반복 인증 시도가 계정 잠금·탐지·서비스 부담을 일으킬 수 있습니다. 원본 구현은 비밀번호를 프로세스 인자로 전달하므로 운영 환경 사용에 적합하지 않습니다.
- `form_post_logger.pl`: CGI POST 값을 로그로 남기는 학습 예제. 실제 비밀번호나 개인정보를 받지 않도록 격리된 테스트 폼에서만 사용하세요. 로그 파일은 공개하지 마세요.

이 코드는 별도 실행 검증을 마친 운영 도구가 아닙니다.
