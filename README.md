# notepad-organized

개인 노트, 허가된 보안 실습 기록, 재사용 가능한 스크립트를 주제별로 정리하는 저장소입니다.

## 저장소 구조

- `notes/`: 개념 정리와 학습 노트
- `labs/`: 본인 소유 또는 명시적으로 허가받은 환경의 실습 기록
- `scripts/`: 반복 작업을 위한 보조 스크립트
- `projects/`: 실행 가능한 예제 프로젝트
- `templates/`: 새 문서를 시작할 때 사용하는 템플릿
- `docs/`: 이용 조건, 안전 수칙, 기여 안내

각 폴더의 `README.md`를 먼저 읽고, 새 문서는 의미 있는 이름과 날짜를 사용해 추가하세요.

## 중요: 안전하고 합법적인 사용

이 저장소의 보안 관련 자료는 교육, 연구, 방어 및 명시적으로 허가된 테스트만을 목적으로 합니다. 타인의 시스템·계정·네트워크에 무단으로 접근하거나, 서비스 방해·정보 탈취·악성코드 배포 등에 사용해서는 안 됩니다.

자료를 사용하거나 변형하는 사람은 적용되는 법률, 계약, 조직 정책을 확인하고 필요한 사전 허가를 받아야 합니다. 오용으로 발생하는 손해와 법적 책임은 해당 행위자에게 있습니다. 저장소 소유자와 기여자는 법률이 허용하는 범위에서 오용으로 인한 책임을 부담하지 않습니다. 이 문구는 법률 자문이 아니며, 위법 행위를 허용하거나 책임을 자동으로 면제하지 않습니다.

자세한 내용은 [안전 및 이용 안내](docs/LEGAL_AND_SAFETY.md)와 [보안 정책](SECURITY.md)을 확인하세요.

## 민감정보 금지

비밀번호, API 키, 토큰, 개인 식별 정보, 실제 대상의 내부 IP·도메인·구성, 허가받지 않은 데이터는 커밋하지 마세요. 예시는 문서용 예약 주소와 명백한 가짜 자격 증명을 사용하세요.
